# HangMan

## How to run
Before running the program, update line 12 in the code

string filepath = "C:\\Users\\tifti\\source\\repos\\Hangman\\words.txt"; 

You want to update the path pointing to wherever you downloaded or placed the words.txt file.

## How it works
Upon running the program you will get prompted with blank letter spaces. 
Guess a letter, if the letter is in any part of the word, it will show up in that space.
If the letter does not exist anywhere in the word, you will lose an attempt and a part of the hangman will be drawn on the terminal.
Try to guess all the letters before running out of attempts!
